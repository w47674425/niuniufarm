# 牛牛农场 · 新世界观开发迭代计划

> 依据：`design/新世界观.xlsx`（策划案，2026-08-27）  
> 现状：当前代码为「打工旅游 v0.3」（5 目的地章节 + 精神系统 + 品牌首页），与新策划案**方向冲突**，需回退重构。  
> 原则：① 每迭代可独立验证、可回滚；② 优先解除"大方向冲突"（主界面 vs 章节），再做增量；③ 所有数值按策划表落地，未定项标 `[待确认]`。

## 迭代 1 · 世界观回退：单主界面 + 拆除章节（工作量最大，最先做）

**目标**：回到"一个牧场一直玩"的主结构；旅行从"独立章节"降级为"彩蛋收集"。  
**关键任务**

- [ ] 合并 5 目的地：`game.start()` 不再进章节选择，新档直开草原式主局（新手礼包开局）；删除 `save:<destId>` 独立槽逻辑，回归单存档（保留旧档迁移：读 `niuniu_dest_*` 并入主档）
- [ ] 地标目标 HUD（goalStat/蒙古包工地）→ 改为常驻"旅行护照"目标提示（替代性地标）
- [ ] 品牌首页保留（方案 A 启动页），主 CTA 改「开始经营/继续牧场」；「选择目的地」入口移除，改为「旅行护照」+「成就」
- [ ] 章节选择弹窗、5 目的地配置（DESTINATIONS）→ 废弃或降级为护照展示数据
- [ ] 涉及：`game.js` `systems.js`（存档）`home.js` `modals.js` `config.js`
- [ ] 验证：新档/旧档加载无错；主页→开局→无任何"目的地"字样；护照显示旅行进度
- [ ] 依赖：无
