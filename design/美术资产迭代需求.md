# 牛牛农场 · 美术资产迭代需求（对齐新世界观 v2026-08-27）

> 依据：`design/新世界观_开发迭代计划.md`、`src/config.js`(META)、`src/art.js`、`scripts/prep_assets.py`、`src/styles.css`
> 现状：游戏逻辑（`config.js` 的 META / 配方 / 卡包 / 怪物）已落地新世界观，但美术资产（`public/img`）、映射表（`art.js`）、生产脚本（`prep_assets.py`）仍停留在旧清单。
> 问题：新卡 / 新 UI / 横屏背景缺失，导致当前新卡在棋盘与图鉴里回退成 emoji 占位，破坏「纸纹水彩手绘」统一性，也阻塞玩法可见性。
> 目标：补齐 **新增 / 缺失修复 / 替换** 三类资产，使图鉴 46+ 卡全亮、护照·成就入口有图标、背景横屏化，全程沿用既有设计语言。

---

## 0. 现状与缺口总览（一句话结论）

- 旧清单资产（约 49 张卡图 + 7 张 UI 图标 + 2 张竖版背景）已就位，但 `factory` 制造厂映射存在却 **PNG 缺失（404）**。
- **新世界观共需补齐 30+ 张卡图**（5 狗品种 / 羊 / 羊毛 / 毛毡 / 燧石 / 蓝莓酱 / 凯撒沙拉 / 飞机 / 6 机票 / 6 打卡图 / 4 怪物）+ **2 张 UI 图标**（护照 / 成就）+ **2 张横屏背景**。
- 生产管线只需扩展 `prep_assets.py` 字典并补 `art.js` 映射，无需改动渲染代码（CSS 的 `.cimg` 正式图体系已支持）。

## 1. 视觉规范（沿用既有，不重定义）

设计语言与配色已在 `src/styles.css` 固化，新资产**必须沿用**，不可另起风格：

| 维度 | 规范（来自 styles.css） |
| --- | --- |
| 设计语言 | 纸纹水彩 + 蜡笔描边 + 手写体 + 硬偏移阴影 |
| 配色·绿底 | `--green-1..4`（#d8f0c0→#4ea83f）；卡底 `--card-bg:#fffdf4` |
| 分类色 | unit `#ffddb0` / res `#efe6c8` / food `#ffd6d6` / build `#cfe3ff` / life `#d9f7d0` / tech `#e9d6ff` / node `#d7f0c8` / item `#e9d6ff` / mon `#ffd0d0` |
| 墨线 | `--ink-line:#5b5340`（主描边）、`--ink-line-soft:#8a8068`（细描边） |
| 主题色 | 金 `--gold:#f2b705`；夜色 `--night-1..3`（#2b3a5e→#15203a） |
| 字体 | 中文 `ZCOOL KuaiLe`；数字 `Patrick Hand` |
| 阴影 | 右下硬偏移 `3px 3px 0 rgba(91,83,64,.35)`（卡牌）/ `2px 2px 0`（UI） |

**插画绘制约束**：透明背景；主体居中占画幅 ~80%；保留 2px 蜡笔墨线不规则描边；主体底部可带轻微硬阴影，但**不要**自带投影（由 CSS 统一加）；夜贼类（mon）用偏冷/暗调呼应 `--night` 体系；机票与打卡图需有「目的地辨识度」（地标剪影）。

## 2. 资产规格标准

| 资产类型 | 导出尺寸 | 格式 | 背景 | 命名规则 | 接入点 |

## 5. 接入与验收（开发侧落地清单）

**步骤 1 · 补源图**：将新资产透明 PNG 放入 `resource/图标/透明背景图标_处理后/`（沿用脚本候选路径）。
- 可复用：`sheep`←`牛牛农场图标/羊.png`；`factory`←`牛牛农场图标/制作.png`。

**步骤 2 · 扩 `prep_assets.py`**：
- `ICONS` 增：`sheep/wool/felt/flint/jam/caesar/plane` + 6 `ticket_*` + 6 `photo_*` + 5 狗品种 + `factory`（共 21 条），均 160×160 `keep_alpha=True`。
- `UI_ICONS` 增：`passport`←`护照.png`、`achievement`←`成就.png`（若无源图需新建），96×96；`market` 维持 160×160。
- `BG` 改：`bg_day`/`bg_night` 源图改为「草原牧场背景图_16x9横版.png」「草原牧场黑夜背景图_16x9横版.png」，输出尺寸 1920×1080。

**步骤 3 · 补 `art.js` 映射**：
- `CARD_ART` 增上述 21 个 type → `"img/<type>.png"`。
- `UI_ART` 增 `passport:"img/ui_passport.png"`、`achievement:"img/ui_achievement.png"`。
- `BG_ART` 路径不变（文件名仍为 `bg_day.png`/`bg_night.png`），仅尺寸变化，无需改键。

**步骤 4 · 生成**：`python scripts/prep_assets.py` → 输出到 `public/img`。

**验收标准**：
1. 所有新卡在棋盘/图鉴不再显示 emoji 占位，图鉴 46+ 卡全亮。
2. 护照、成就入口有图标可点开空面板。
3. 横屏背景（1920×1080）铺满 `#app` 不拉伸、不露 CSS 渐变底。
4. 夜晚 4 级怪物有手绘形象，攻/血条正常。
5. `factory` 制造厂图正常显示（修复 404）。

## 6. 待确认决策点

- **D1 5 狗品种**：各做独立插画（品种辨识度优先，推荐） vs 统一牧羊犬图 + 配色/项圈区分（省成本）。
- **D2 变异牛（12 种）**：是否做专属插画（收藏/付费价值） vs 维持 `cow.png` + 稀有度角标（里程碑 A 即可，专属插画推迟到 C）。
- **D3 背景**：纯插画铺满 vs 保留 CSS 水彩渐变 + 插画层（`#app.bgimg` 已支持，二选一确认观感）。
- **D4 机票 / 打卡图风格**：写实地标剪影（辨识度强） vs 统一卡通机票/相框模板（绘制快、风格统一）。

> 以上确认项不影响里程碑 A 的「修复 + 高优新增」起步；D2/D4 可直接采用后备方案先过试玩，正式稿在 C 阶段收敛。
