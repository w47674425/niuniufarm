## 0. 设计立意（先结论）

把现有"牧民打工→卖牛卖奶换金币→买卡包扩产"的底层引擎**保留为通用打工引擎**，但把**上层包装整体改为"环游世界建造"**：

- **打工** = 通用引擎（牧民采/养/挤奶 → 卖牛卖奶换**机票**）。牛链仍是硬币(机票)主源（cattle-centric 红线不变）。
- **旅游** = 每章选一个**目的地主题**：该主题自带一条**专属特色产线** + 一个**地标建筑**作为本章目标。不同目的地 = 不同的生产谜题（包装变了）。
- **机票** = 货币/基金。开局给"过往旅行攒下的机票"作起步预算；打工赚机票、花机票买装备包 + 建地标。
- **生存压力** = **食物 + 精神（士气）**，无夜间怪物。精神归零工人"想家离职"，食物断供工人"饿跑"——失败态从"被打死"变为"没人干活→建不成地标"。

**经济健康性**：本重构仍是通胀收敛方向。机票双 sink = 买装备包 + 建地标（大额），且移除战斗后少了一个金币/人口的消耗口，需用"地标建造"这一硬性大额 sink 补回——设计中地标消耗机票+专属材料，正好对齐 `经济循环模拟结论` 的"加真 sink"建议。

## 1. Fun Hypothesis（一句话）

**这游戏好玩的核心是：用一套"打工赚钱"的通用引擎，去攻克一个个主题截然不同的目的地——每个地方逼你学一套新产线、攒钱建起它的地标，而"食物+精神"双维度让你在拼命打工和喘口气之间反复权衡。**

## 2. Design Pillars（不可妥协的体验标准）

## 3. Core Loop（三层钩子，主题化）

### 3.1 Moment-to-moment（0–30s，不变）
```
拖卡A 压到 卡B → 进度条 → 产出新卡 / 触发动作
```
最短爽点单元，反馈即时。

### 3.2 Session loop（一个月亮年 Moon ≈ 2–3min 实时；单目的地整局 20–40min，主题化）[PLACEHOLDER: Moon→分钟映射待引擎定]
```
[打工生产] → 月尾结算(喂人[食物] + 精神结算 + 卖卡换机票 + 买装备包) → 推进地标建造
```
**移除**：`maybeSpawnMonster()` 夜袭（覆盖 GDD §3.2）。
**新增**：月尾 `settleSpirit()` 精神结算（过度打工掉精神、休闲恢复）；`buildLandmark()` 进度。
HUD：常驻「本章目的地卡」（地标进度条）+「食物条」+「精神条」+ 机票计数。

### 3.3 Long-term（数小时–数周，跨 run，护照集章）
```
选目的地 → 攒机票+材料建地标(达成) → 护照集章 + 解锁下一档目的地 → 换更高阶目的地重开
```
目的地分档（入门/进阶/高阶/顶级），护照章（passport stamps）跨局永久保存，构成长期追求（支撑 GDD §8-D 留存）。**每目的地独立存档槽 + 可重启**（见 §4.9）：单局 20–40min 即一段完整旅程，可随时换目的地或重开，零惩罚。

## 4. 系统规格（Systems，修订版）

### 4.1–4.4 卡牌堆叠 / 配方 / 时间 / 经济（大体沿用 GDD §4.1–4.4）
- 堆叠、配方引擎、月亮年、经济闸门（cardCap/Dustbin）**不变**。
- **货币重皮肤**：`coin` 显示名改为 **机票**（内部字段名保留 `coin` 不动，仅文案/图标换皮）。`cardCap` 仍是防死锁安全网。

### 4.5 食物与人口（修订：无饿死剧情化）
- **Purpose**：食物 = 第一生存维度。
- **Inputs**：每月 `feedCost = herderCount × 1 食物`。
- **Outputs**：足额→存活；不足→缺额工人"饿跑"（离场，非死亡叙事）。
- 来源/消耗同 GDD §4.5（食物卡包/草料链/烹饪链，牛链为中央支柱）。

### 4.6 精神（士气）系统（**新增，替代战斗系统**）

- **Purpose**：把"无限打工"变成有代价——精神是第二生存维度，制造"拼命 vs 喘息"张力（替代原战斗张力）。
- **设计立意（重要）**：在"打工旅游"里，休闲/景点本就是旅游幻想的载体，**精神系统正是"旅行感"落点**——你建茶馆/温泉/观景台不只是回血，是在"享受这趟旅行"。故精神机制应被设计成**奖励**而非纯惩罚。
- **推荐模型：双轨（Per-worker 精神 + Team morale）**
  - **A. 每工人精神 `spirit ∈ [0,100]`（初始 100）**
    - **消耗 Sinks**：
      1. 主动打工损耗：工人卡参与一次配方结算，`spirit -= dWork`（极小，按"真实产出动作"计，不按拖拽次数——避免惩罚聪明的组合规划）。
      2. 夜班惩罚 ×2：夜间阶段（原夜袭窗口）仍让工人上工，损耗翻倍。把"夜的危险"换成"夜的诱惑"。
      3. 单调倍率：同一工人连续只做同一种配方，累计 `monotony` 栈 → 损耗 ×(1+mono)，换任务/休息清零。推动产线多样化（与各地多线目标协同）。
      4. 饥饿耦合：本月食物不足，`spirit` 损耗 ×1.5（又饿又干=崩溃）。
    - **恢复 Sources**：
      1. 休闲建筑（主题核心）：咖啡馆☕(通用)/茶馆🍵(古镇)/温泉♨️(冰岛·海岛)/观景神社(东京)。工人"闲置/指派"于休闲节点→持续回精神。
      2. 闲置休息：未派工的工人缓慢回精神。
      3. 地方特饮(消耗卡)：东京清酒🍶/海岛椰饮🥥→即时 +精神（用专属产线，绑建造）。
      4. 地标里程碑：每凑齐一份地标材料→**团队精神一次性大涨**（"我们在建漂亮东西"），正向反馈，利于 20–40min 节奏。
    - **归零后果**：该工人"想家离职"（卡移除离场；其上装备/产出卡留在 board，符合 P4）。可下月通过卡包/事件再雇——软失败、可恢复，替代"死亡"。
  - **B. 团队士气 `morale = avg(spirit)`（派生 0–100）**
    - 驱动全局 `moraleMult`：
      - `avg ≥ 70` → ×1.1（开心工人建得更快，奖励良好管理）
      - `40 ≤ avg < 70` → ×1.0
      - `avg < 40` → ×0.8 起，最低 ×0.5（avg=0）
    - 这是系统性压力：忽视精神→全盘变慢。
- **UI 建议**：每张工人卡显精神环；HUD 显团队士气条 + 最低精神预警。
- **Tuning（面向 20–40min）**：使"纯打工不喘息"约在 15–20min 触危机（有人离职/士气<40），逼玩家介入；早期建 1 个休闲建筑即可撑到 40min。
- **Edge cases**：恢复卡有冷却防无限刷；离场工人不丢 board 物资。
- **覆盖 GDD**：原 §4.6 战斗（HP/ATK/武器/克制/Boss）**整体移除**；挑战内容改为可选"极端天气/突发状况"事件卡，非战斗。

### 4.7 地标建筑系统（**新增，本章目标**）
- **Purpose**：把"攒钱"变成"攒钱+攒材料建一个看得见的目标"，给每章明确终点。
- **Player experience goal**：玩家盯着地标进度条，规划"这周先凑齐铁锭还是先攒机票"。
- **Inputs**：目的地专属 `landmarkRecipe`（需 机票 + 该目的地专属材料若干）。
- **Outputs**：材料齐 + 机票足 → 拖到「工地」卡 → 进度条 → 地标落成 → 本章达成（护照集章 + 解锁下一档）。
- **Edge cases**：地标在建期间可被 monster? 无；可被误拆？不允许（锁定）。
- **Failure states**：材料扣除但地标未生成 → 回滚。

### 4.8 目的地主题系统（Goals/Destination，核心）
- 每个目的地 = 一套主题包：`themeNodes`（专属资源点）、`signatureChain`（专属产线）、`landmark`（地标+配方）、`spiritProfile`（精神风味）、`starterPack`（出发装备包）、`shopPackIds`（专属进阶包）。
- 选定目的地即发放 `starterPack`（免费，含"过去机票"起步预算 + 主题起点卡）；商店解锁 `shopPackIds`。
- 详见 §5。

### 4.9 存档与重启（每目的地独立，新增）

- **Purpose**：每目的地 = 一个自包含 run（20–40min），支持独立存档与重启，零惩罚切换（呼应 P4）。
- **模型**：
  - **每目的地独立存档槽** `save:<destId>`：存该章 board、工人、机票、专属材料、地标进度、各工人精神。
  - **全局 Meta 槽** `save:meta`（跨 run/重启持久）：护照章（已达成目的地）、已解锁目的地、旅行者称号/皮肤。重启某目的地**不**清 Meta。
  - **重启** = 清空 `save:<destId>` → 重新发放 `starterPack` + `startTickets` → 从首月重开。成本 < 5s（P4）。游戏内"确认重启？"即可（非危险文件操作）。
- **章节选择界面**：列出所有目的地，各自显状态（锁定 / 进行中%- / 已达成+印章），并提供「继续 / 重启 / 新游戏」三动作。
- **解锁链**：需先达成低档目的地才解锁下一档（草原→海岛·古镇→东京→冰岛）；但每档可独立重玩/重启，Meta 章永久保留。
- **Edge cases**：重启中若正在地标建造，进度回滚到 0（重发起点）；断线/退出自动存最新月尾快照。

### 5.1 "过去机票"起步预算
- 每章开局直接发放 `startTickets`（"过往旅行攒下的机票"），数值 `[PLACEHOLDER]`。
- 建议梯度（与档位挂钩，越高级起步机票越多以降低劝退）：草原 60 / 海岛·古镇 100 / 东京 160 / 冰岛 240 `[PLACEHOLDER]`。rationale：单局 20–40min 内，让每章前 ~3–5min 不被"零启动"卡死，但远不够建地标（地标机票见 §7），仍需打工 ~15–35min。
- 实现：进入目的地时 `coin += startTickets`，并播放"翻出旧机票"动效（轻量）。

### 5.2 卡包差异（用户重点：不同目标不同卡包）
- **出发装备包（选定即免费发）**：含 `startTickets` 等价卡 + 该目的地 1 张主题起点卡（草原→牧草田、海岛→椰子树、东京→和牛、冰岛→冰原牛）。
- **商店专属进阶包（解锁）**：草原无（教学）；海岛→海岛补给包¥15；古镇→面点包¥15；东京→寿司料理包¥30；冰岛→极地工程包¥40。价格梯度对齐现有包价（basic10/ranch20/building30）。
- 通用包（basic/ranch/animal/building）仍全目的地可用——它们是"打工引擎"的通用补给，目的地包是"主题拼图"。

## 6. 经济系统复核（Sources & Sinks，v0.2）

### 6.1 闭环
```
打工生产 → 卖牛/奶/货 → 机票
   机票 ─┬─→ 买装备包（通用补给，hard sink，回流生产）
         └─→ 建地标（机票 + 专属材料，大额 sink = 本章终点）
投资装备包 → 产更多机票 → 更快建成地标
```
核心张力：**花在装备包上的机票没存进地标基金，但装备包让你产币更快**；同时**过度打工掉精神**，逼你穿插休闲——三重节奏决策（投资/储蓄/喘息）。

### 6.2 Sources / Sinks
| 项 | 类型 | 说明 | 变化 |
|----|------|------|------|
| 卖牛/奶/货 | Source | 机票主源（cattle-centric 红线） | 不变 |
| 买装备包 | Sink | 通用补给 | 不变 |
| **建地标** | **Sink（新增大额）** | 机票 + 专属材料，本章终点 | **新增**（替代原"旅游基金出发"） |
| 食物消耗 | Sink（软） | 每月喂人 | 不变（去剧情化） |
| **精神消耗/恢复** | **维度（新增）** | 替代战斗张力 | **新增** |
| 任务奖励 | Source | 现有 10 任务 | 建议部分改"花钱型"（报销式） |

### 6.3 通胀论证（对照 GDD §7）
