拖拽堆叠类经营生存小游戏 · 抢先体验版

▶ 开始游玩（手机/电脑都行）
首次进入请点一下屏幕或拖一张卡，背景音乐会开始

130 秒上手

  • 核心玩法：按住卡片拖动，把一张卡叠到另一张卡上，触发生产 / 建造 / 繁殖 / 战斗。
  • 牧民 → 拖到资源卡（草堆、木桩等）上 → 产出资源。
  • 食物（汉堡 / 熟肉）→ 拖到牧民身上 → 喂饱，否则天黑会饿死。
  • 牛 → 长大了拖到「市场」卡片上 → 卖出换金币 → 用金币买卡包扩充卡组。
  • 右上角 ❔ 帮助里有完整配方说明，卡牌图鉴会记录你发现过的卡。

2这一版重点测什么

开发者最想确认的 4 件事（不用全测，挑你顺手的玩就行）：

  1. 开局难度：前 3 天是不是太难 / 太闲？能不能顺利养出第一头牛并卖掉？
  2. 夜晚威胁：天黑刷出的小偷 / 大盗会不会主动扑过来？打得过吗？有没有“被打懵”的感觉？
  3. 经济手感：金币来得顺不顺？买卡包、扩建（棚 / 仓）值不值？会不会一下子“钱荒”卡死？
  4. 卡位 / 整理：棋盘塞满后，有没有「垃圾桶」能销毁没用的卡？塞满又没处扔会不会死锁？

3已知的设计取舍（先心里有数）

现象是 bug 吗说明
背景是单张草原图循环否昼夜切换目前只换色调，背景图不变
背景音乐只有一首循环否暂未做白天 / 夜晚两版配乐
前 3 天可能饿死牧民可能偏难正是这次要测的“早期坡度”问题
棋盘偶尔满、需要清卡设计如此靠「垃圾桶」卡解决，麻烦请反馈是否够用
进度自动存档在本地浏览器否换设备 / 清缓存会丢档，属预期
